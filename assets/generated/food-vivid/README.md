# Vivid food sprites

These files are generated, non-destructive color and edge treatments of the
CC0 food sprites stored under `assets/third_party/oga/food/food-ocal/32x32`.

Regenerate them with:

```powershell
python scripts/polish-food-pixel-art.py
```

The treatment preserves the original 32×32 pixel grid while improving
saturation, contrast, silhouette readability, and directional pixel lighting.
See `assets/third_party/oga/food/food-ocal/food-OCAL.txt` for source details.
